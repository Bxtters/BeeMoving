# BeeMoving
A simple game project named BeeMoving

`Camera_MoCap.cs` is the motion-capture display for Unity 6000.0.82f1. The same script is packed inside `Handline.zip` at `Handline/Assets/Scripts/Runtime/Camera_MoCap.cs`. Press Play after opening that Unity project. The stage draws up to six people with MoveNet Lightning, keeps the camera picture off screen and off disk, and drops facial points. Hands end at the wrist because the model has no finger joints.
